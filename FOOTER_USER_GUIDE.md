# Footer Configuration User Guide

## Overview
The Footer Configuration tool allows you to manage and customize all aspects of your website's footer from a single, easy-to-use interface.

## Accessing the Footer Editor
1. Log in to the GETfund CMS
2. Navigate to the Footer Settings section
3. The editor will load your current footer configuration

## Using the Footer Editor

### Navigation
The editor is organized into 6 tabs, each managing different aspects of the footer:

---

## 1. Organization Info Tab

### Logo URL
- **Purpose**: Set the logo that appears in the footer
- **How to use**:
  1. Enter the URL path to your logo image
  2. Example: `/images/logos/getfund-logo-light-main.png`
  3. A preview will appear below the input field showing how the logo looks
- **Tips**: Use a light-colored logo for better visibility on dark backgrounds

### About Text
- **Purpose**: Brief description about your organization
- **How to use**:
  1. Enter up to 500 characters of text
  2. The character counter shows remaining space
  3. Keep it concise and informative
- **Example**: "Supporting the delivery of quality education across Ghana through sustainable funding and infrastructure development."

---

## 2. Styling Tab

### Background Color
- **Purpose**: Customize the footer's background color
- **How to use**:
  - **Option 1**: Click the color picker box and select a color visually
  - **Option 2**: Enter a hex color code directly (e.g., `#1e3a5f`)
- **Features**:
  - Live preview shows how the color will look
  - Default color is dark blue (`#1e3a5f`)
- **Tips**: Choose colors that provide good contrast with white text

---

## 3. Contact Info Tab

### Phone Number (Required)
- **Purpose**: Main contact phone number
- **How to use**: Enter your phone number in any format
- **Example**: `+233 (544) 323-020`
- **Note**: This field is required and must be filled

### Email Address (Required)
- **Purpose**: Primary contact email
- **How to use**: Enter a valid email address
- **Example**: `info@getfund.gov.gh`
- **Note**: This field is required and must be filled

### Physical Address
- **Purpose**: Office location
- **How to use**: Enter your complete address (can use multiple lines)
- **Example**:
  ```
  No. 42, 4th Close
  Airport Residential Area
  Accra, Ghana
  ```

---

## 4. Office Hours Tab

### Weekday Hours
- **Purpose**: Display your working hours during weekdays
- **How to use**: Enter your operating hours in a readable format
- **Example**: `Monday - Friday: 8:00 AM - 5:00 PM`

### Weekend Hours
- **Purpose**: Display weekend availability
- **How to use**: Enter weekend hours or indicate if closed
- **Examples**:
  - `Saturday - Sunday: Closed`
  - `Saturday: 9:00 AM - 1:00 PM, Sunday: Closed`

---

## 5. Social Media Tab

Configure links to your social media profiles. The editor supports:

- **Facebook**: Enter your Facebook page URL
- **X (Twitter)**: Enter your Twitter/X profile URL
- **LinkedIn**: Enter your LinkedIn company page URL
- **Instagram**: Enter your Instagram profile URL
- **YouTube**: Enter your YouTube channel URL
- **WhatsApp**: Enter your WhatsApp contact URL

### How to use:
1. Enter the full URL for each platform you use
2. Leave blank any platforms you don't use
3. Format: `https://facebook.com/yourpage`

### Examples:
- Facebook: `https://facebook.com/getfundghana`
- Twitter: `https://twitter.com/getfund_gh`
- LinkedIn: `https://linkedin.com/company/getfund`

---

## 6. Quick Links Tab

### Purpose
Add custom navigation links that appear in the footer for quick access to important pages.

### How to use:

#### Adding a Link
1. Click the **Add Link** button
2. A new link form will appear with two fields:
   - **Link Name**: The text that will be displayed
   - **Link URL**: Where the link should go

#### Example Links:
```
Name: About Us          URL: /who-we-are
Name: Contact           URL: /contact
Name: Privacy Policy    URL: /privacy
Name: Terms of Service  URL: /terms
Name: Careers           URL: /careers
Name: FAQs              URL: /faq
```

#### Removing a Link
- Click the red **Remove** button next to any link you want to delete

#### Reordering Links
- Links appear in the footer in the same order they're listed in the editor
- To reorder: remove and re-add links in your preferred order

---

## Saving Your Changes

### Save Button
1. After making any changes, click **Save Changes** at the bottom right
2. The button will show "Saving..." while processing
3. A green success message confirms your changes were saved
4. Changes are immediately live on your website

### Reset Button
- Click **Reset** to discard all unsaved changes
- This reloads the current saved configuration

---

## Validation Rules

The editor enforces these rules:
- **Phone number** is required (cannot be empty)
- **Email address** is required (cannot be empty)
- **About text** limited to 500 characters
- **Background color** must be a valid hex code format (#RRGGBB)

If validation fails, you'll see a red error message explaining what needs to be fixed.

---

## Tips for Best Results

1. **Logo**: Use a transparent PNG for best results
2. **About Text**: Keep it under 300 characters for better readability
3. **Colors**: Test your color choice with the preview to ensure readability
4. **Phone/Email**: Double-check these for accuracy before saving
5. **Social Links**: Include the full URL starting with `https://`
6. **Quick Links**: Limit to 5-8 links to avoid cluttering the footer
7. **Office Hours**: Be specific and clear about your availability

---

## Troubleshooting

### Changes Not Saving
- Check that phone and email fields are filled
- Ensure background color is a valid hex code
- Check browser console for any error messages

### Logo Not Appearing
- Verify the logo URL path is correct
- Ensure the image file exists at that location
- Check that the image format is supported (PNG, JPG, SVG)

### Preview Looks Different Than Website
- Clear your browser cache
- Wait a few moments for changes to propagate
- Refresh the website page

---

## Support

If you encounter any issues or need assistance:

3. Contact your system administrator if problems persist
